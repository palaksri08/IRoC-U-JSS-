# IRoC-U-JSS-
Sensor integration in IRoC-U 2025 will play a critical role in real-time decision-making, environment perception, and autonomous movement, simulating real-world space exploration scenarios.
BMP 390 is used as the temperature and pressure sensor
ICM 20948 is used as the accelometer and magnetometer
NEO-M8Q is the GPS sensor
Arduino integrated with Teensy 4.1 is used
